# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [1.0.0] - 2025-11-20

### ✨ Añadido
- Sistema de autenticación sin email (registro y login)
- Dashboard de monitoreo en tiempo real con gauge circular
- Conexión MQTT con HiveMQ Cloud (TLS/SSL)
- Control remoto de electroválvula con confirmación
- Historial de lecturas con gráfico interactivo
- Sistema de notificaciones locales con 3 niveles de prioridad
- Base de datos SQLite para usuarios y lecturas
- Limpieza automática de datos antiguos (>10 horas)
- Configuración completa (notificaciones, perfil, almacenamiento)
- Tema oscuro con Material Design
- Navegación con BottomNavigationBar y Drawer
- Documentación completa en español
- Soporte para Android 6.0+ e iOS 12.0+

### 🔒 Seguridad
- Hash SHA-256 para contraseñas
- Conexión segura TLS/SSL con MQTT
- Validaciones de entrada en formularios
- Sesión única por usuario

### 📱 Plataformas
- Android (API 23+)
- iOS (12.0+)

### 🎨 Interfaz
- Tema oscuro por defecto
- Fuente Google Poppins
- Colores dinámicos según nivel de alarma
- Animaciones y transiciones suaves

### 📚 Documentación
- README.md completo
- Guía de instalación detallada
- Comentarios en español en todo el código
- Estructura de proyecto documentada
